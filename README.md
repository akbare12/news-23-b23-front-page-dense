## How it is built

`draw.py` (PIL) renders `entry.png` (1024×1024). `main.py` is stdlib-only: it validates the PNG header by hand and copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. All scenes are drawn illustrations, not photographs.
